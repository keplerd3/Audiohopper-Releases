# Audiohopper Releases

This repository contains official downloadable releases and public release
materials for Audiohopper. It intentionally does not contain the private
development repository, user data, imported study materials, local dictionaries,
or internal build logs.

## Current release

`v0.1.0-beta.1` is a macOS Apple Silicon (ARM64) Beta.

- Download the DMG from the [v0.1.0-beta.1 pre-release](https://github.com/keplerd3/Audiohopper-Releases/releases/tag/v0.1.0-beta.1).
- Read [the installation guide](docs/INSTALL_MACOS.md) before opening it.
- Verify the download using [SHA256SUMS.txt](SHA256SUMS.txt).

This Beta is ad-hoc signed and is not notarized by Apple. macOS may show a
Gatekeeper warning on first launch; use the per-app Control-click **Open** flow
described in the installation guide. Do not disable Gatekeeper system-wide.
